# Aura — задание на набор иконок (для облачного агента)

**Как использовать:** скопируй этот текст целиком в задачу облачному агенту и
приложи скриншот-референс «After». Агент не имеет доступа к компьютеру и к
исходникам Aura — всё, что ему нужно, есть ниже. На выходе нужен **один
самодостаточный HTML-файл** с набором иконок и демонстрационной сеткой.

---

## 1. Что за продукт

**Aura** — утилита голосового ввода для Windows. Пользователь нажимает
глобальную горячую клавишу, говорит, и текст печатается прямо в активное окно
любой программы. Распознавание может идти локально (Whisper.cpp, NVIDIA
Parakeet) или через облако (Gemini, OpenAI, Groq, Hugging Face).

Интерфейс — компактное тёмное окно настроек, не сайт и не мобильное приложение.
Слева вертикальное меню из шести пунктов, справа — карточки и сворачивающиеся
строки. Есть отдельное меню в системном трее и небольшие кнопки действий.

Визуальный характер: тихий, точный, «stealth command deck». Никакой игривости,
иллюстраций и декора. Тёмный ахроматический фон, светлый текст, редкий
оранжевый акцент. Иконки должны помогать сканировать список взглядом, а не
привлекать внимание к себе.

### Палитра

| Роль | Цвет |
|---|---|
| Фон окна | `#090909` |
| Поверхность карточки | `#0d0d0d` / `#101010` |
| Основной текст | `#f5f7fa` |
| Вторичный текст | `#9ba6b3` |
| Приглушённый текст | `#737f91` |
| Акцент (редко) | `#ff4200` |

Шрифт в приложении — Onest. В демо-файле можно использовать системный
`"Segoe UI", system-ui, sans-serif`; главное — иконки, не шрифт.

### Где живут иконки

1. **Левое меню настроек** — 6 пунктов, иконка 18 px, активный пункт оранжевый.
2. **Верхняя панель окна** — свернуть / закрыть, 14 px.
3. **Трей-меню** — компактный список, иконки 15 px.
4. **Карточки и аккордеоны** — иконка 16–20 px рядом с заголовком или в плашке 28 px.
5. **Кнопки и строки действий** — 13–16 px.
6. **История** — фильтры-пилюли 13 px, действия 15 px.
7. **«О программе»** — плитки 32 px с глифом 18 px.

Главный критерий: глиф должен узнаваться на **16 px** и не спорить с текстом.

## 2. Визуальный референс

Приложен скриншот «After». Смотреть на него, но **не копировать конкретные
иконки** (это чужой продуктовый набор).

Что берём:

- тонкую линию одинакового веса;
- круглые концы и стыки;
- простые геометрические силуэты (дом, документ, папка, человек, стикер);
- крупные поля внутри глифа, отсутствие «забитости»;
- одинаковую оптическую плотность: ни один глиф не тяжелее соседа;
- спокойный ритм в списке.

Что не берём:

- цветные бейджи со скриншота — у Aura набор строго монохромный;
- конкретные формы Tessera 1:1;
- градиенты, тени, объём, свечения;
- «милые», игровые или иллюстративные формы.

Чего избегать (признаки «нейросетевого» набора):

- случайная толщина: где-то 1.5, где-то 2.5;
- шестерёнки и глифы с десятком мелких зубцов;
- разные оптические размеры: один глиф 12 px, соседний 20 px;
- лишние внутренние линии «для детализации»;
- стоковые Lucide / Feather / Phosphor без переработки;
- несогласованные радиусы и углы.

### Частые слабые места, которые надо проверить отдельно

- **Игровой режим.** Не сплюснутая капсула. Нужен узнаваемый контроллер:
  корпус, крестовина, две кнопки — и нормальная высота, а не полоска.
- **Документ.** Не «планшет» с тремя линиями. Лист с загнутым углом или
  текстовый силуэт, который читается как документ.
- **Чип и облако.** Это самые банальные AI-клише. Если используешь их, добавь
  продуктовую деталь: волну голоса, локальный монитор, эквалайзер. Одинокий
  чип и одинокое облако — недостаточно.
- **CUDA.** Возьми официальный знак NVIDIA (он уже используется на сайте Aura,
  `website/index.html`), впиши его в 24-сетку как заливку в `currentColor`. Не
  рисуй самодельный чип с молнией.
- **Ключ.** Не диагональная палочка с крошками. Чистый ключ: кольцо, стержень,
  два зубца.
- **Sparkles.** Не «звезда и точка» и не волшебная палочка. Одна чистая
  четырёхлучевая звезда или две звезды без точки.
- **Zen и Sci-Fi.** Должны узнаваться без подписи. Открытая дуга и кольцо с
  планетой — слишком абстрактно; проверь на 16 px и на человеке, который не
  знает названия темы.

## 3. Жёсткие ограничения

| Параметр | Значение |
|---|---|
| viewBox | `0 0 24 24` |
| Ключевые линии | 18 × 18, поля 3 px; круглые формы r = 9 |
| Штрих | 2 px, `stroke-linecap="round"`, `stroke-linejoin="round"` |
| Цвет | `currentColor` для UI-иконок; **оригинальные цвета — у знаков облачных провайдеров** |
| Заливки | только смысловые точки, треугольник Play, шкала размера модели и фирменные знаки |
| Тени / свечения | запрещены |
| Бренд-логотипы и флаги | официальные знаки NVIDIA (CUDA и Parakeet), OpenAI (Whisper), Gemini, Groq и Hugging Face разрешены; **знаки провайдеров — в оригинальных цветах**, остальные — `currentColor`; флаги запрещены |
| Внешние библиотеки | нельзя копировать готовые наборы; пути рисуются вручную |
| Генерация картинок | запрещена; только SVG-пути |

Дополнительно:

- каждый глиф обязан читаться на 16 px;
- в одном контексте не должно быть двух неразличимых силуэтов;
- набор должен работать и на светлом фоне (по желанию — toggle в демо);
- никаких внешних шрифтов, картинок и CDN в HTML-файле.

Действует для «Язык интерфейса», «Язык распознавания» и «Язык перевода».

### 4.11. Утилитарные глифы и громкость

Используются в кнопках, тостах, селектах и динамических строках. Список
обязательный; часть совпадает с поверхностями выше — держать один канонический
глиф и алиасы.

```
minimize       close          chevron-down   chevron-right  chevron-left
arrow-right    check          check-circle   alert-circle   info-circle
search         copy           trash          download       upload
reset          eye            eye-off        plus           external
star           play           key            terminal       database
sparkles       cloud          chip           waveform       globe
gamepad        power          mic            doc            keyboard
clock          settings       layers         gauge          pencil
list           timer          book           text-cursor    replace
selection      refresh        bolt           hexagon
```

**Громкость — не один глиф, а четыре состояния:**

| Ключ | Состояние |
|---|---|
| `volume-0` | выключено / mute |
| `volume-1` | тихо |
| `volume-2` | средне |
| `volume-3` | громко |

Иконка меняется по порогам слайдера (0 / 1–33 / 34–66 / 67–100). В демо
покажи все четыре состояния и, если возможно, слайдер с плавным crossfade.
Одиночный динамик без градаций не принимается.

Если для слота нужен свой глиф, добавь его и задокументируй. Не оставляй ни
один слот без иконки.

### 4.12. Облачные провайдеры (4)

| Ключ | Провайдер |
|---|---|
| `provider-gemini` | Gemini |
| `provider-groq` | Groq |
| `provider-openai` | OpenAI |
| `provider-huggingface` | Hugging Face |

Используй официальные знаки. Если приложены файлы `Gemini.svg`, `Groq.svg`,
`Open AI.svg`, `Hugging Face.svg` — бери формы и **оригинальные цвета** из них.
Это единственное цветовое исключение в наборе: остальные иконки остаются
`currentColor`. Кастомный сервер остаётся текстом, без иконки.

Два уточнения, которые легко сделать неправильно:

- **Gemini** — не один градиент. В оригинале звезда-маска и группа размытых
  цветных пятен (`feGaussianBlur`); при упрощении до линейного градиента знак
  становится почти полностью синим. Id маски и фильтров обязаны быть
  уникальными для каждого рендера.
- **OpenAI** — белый (`#FFFFFF`), а не `currentColor`. Иначе в селекте знак
  наследует серый цвет строки и становится оранжевым при наведении.

### 4.13. Что НЕ нужно

- логотип Aura — отдельный бренд-ассет;
- кастомный провайдер (custom) — только текст, без иконки;
- флаги и коды языков — только текст / бейдж `RU`;
- ручки тумблеров, прогресс-бары, VU-метр, анимация волны в оверлее;
- кнопка maximize — её нет в окне.

## 5. Что сдать

**Один самодостаточный HTML-файл** (`icon-set.html`). Открывается двойным
кликом, без сервера, без сборки, без внешних ресурсов.

Внутри:

1. **Все иконки** — inline `<svg>` с фиксированными именами. Не `<img>`, не
   data-URI, не внешний спрайт: каждый глиф должен быть отдельным SVG-элементом,
   чтобы его можно было скопировать.
2. **Демо-сетка**: каждая ячейка — глиф 24 px, глиф 16 px, имя и одна строка
   смысла. Категории: навигация, окно, трей, движки, модели, разделы, карточки,
   история, «О программе», звук, действия.
3. **Счётчик** «показано / всего».
4. **Фильтр по категориям** (по желанию).
5. **Переключатель 16 / 20 / 24 / 32** (по желанию).
6. **Тёмный фон Aura** (`#090909`, поверхности `#101010`), светлый текст.
7. **Контекстные макеты** — сильно желательно. Агент не видел Aura, поэтому вот
   словесные эскизы:

- Навигация: 6 строк, иконка 18 px + подпись; активная строка — оранжевая плашка.
- Аккордеон: плашка 28 × 28 с иконкой, заголовок, подсказка, шеврон справа.
- Карточка модели: иконка 16 px, название, размер файла, кнопка скачать / галочка.


- Иконки 15 px, строки 32 px, тёмная поверхность, без теней.

### Эскиз «О программе»

- 4 строки: плитка 32 × 32 с иконкой 18 px, заголовок, описание, шеврон.
- Строки: тур, что нового, баг-репорт, звезда GitHub.

### Эскиз звуковых тем

- Список или сетка: иконка 16 px + название темы + галочка у выбранной.

### Эскиз провайдеров

- Четыре плитки или строки: Gemini, Groq, OpenAI, Hugging Face.
- Официальные знаки в `currentColor`, подпись под каждым. Кастомный сервер — без иконки.

### Эскиз громкости

- Четыре состояния `volume-0…volume-3` рядом: выкл, тихо, средне, громко.
- Если возможно — слайдер, который переключает иконку по порогам
  (0 / 1–33 / 34–66 / 67–100) с плавным crossfade, а не мгновенной заменой.

### Эскиз истории

- Поиск с иконкой 15 px.
- Три пилюли: «Все», «Облако», «Локально» с иконками 13 px.
- Строка записи с копированием и удалением (15 px).

## 6. Как возвращать результат

- Полный HTML в одном блоке кода, без сокращений («...»).
- После кода — короткая записка:
  - сколько канонических глифов;
  - какие решения приняты (сетка, штрих, семейства, спорные места);
  - какие иконки считаешь слабыми и почему.
- Если HTML не помещается в один ответ — разбей на два сообщения, но не
  сокращай код.

## 7. Критерии приёмки

- [ ] Все ключи из раздела 4 существуют и рендерятся.
- [ ] Ни одного hex-цвета в SVG; только `currentColor`.
- [ ] У всех глифов `viewBox="0 0 24 24"`, штрих 2, round caps/joins.
- [ ] Все глифы читаются на 16 px.
- [ ] Нет двух неразличимых силуэтов в одном контексте.
- [ ] Демо-сетка показывает все канонические глифы с именами.
- [ ] Счётчик совпадает с фактическим числом.
- [ ] Есть четыре состояния громкости `volume-0…volume-3`.
- [ ] Есть четыре официальных знака провайдеров: Gemini, Groq, OpenAI, Hugging Face.
- [ ] HTML открывается с `file://` без сервера и внешних ресурсов.
- [ ] Есть хотя бы 4 контекстных макета (навигация, аккордеон, модель, трей/история).
- [ ] Нет `console.error` при открытии.

## 8. Чего не делать

- Не встраивать иконки в реальное приложение — только HTML-демо.
- Не брать готовые Lucide / Feather / Phosphor без переработки.
- Не добавлять цветные бейджи: набор строго монохромный.
- Не рисовать 100+ иконок «на всякий случай»: только слоты из раздела 4.
- Не генерировать SVG картинкой — только ручные пути.
- Не использовать внешние шрифты и CDN: файл должен быть автономным.

## 9. Как сравнивать с параллельной версией

1. **16 px.** Каждый глиф узнаётся без подписи?
2. **Силуэты на 64 px.** Формы разные, а не один трафарет с разными деталями?
3. **Вес.** Нет глифов жирнее или бледнее соседей?
4. **Семейства.** Модели читаются как шкала; звуки отличаются силуэтом;
   движки не путаются.
5. **Контекст.** В навигации, трее и карточках иконки не спорят с текстом.
6. **Покрытие.** Все слоты закрыты, ничего не забыто.
7. **Демо.** Сетка с названиями, счётчик, размеры, контексты.
8. **Признаки «нейросетевого».** Случайный штрих, мелкие зубцы, несогласованные
   радиусы, лишние детали.

Сравнивать по этим пунктам, а не по «нравится / не нравится».
