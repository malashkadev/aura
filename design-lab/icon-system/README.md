# Aura — Icon System (monochrome proposal)

Демонстрация нового набора иконок для рабочего интерфейса Aura. **В `src/` ничего не
встроено** — это отдельный макет для рассмотрения.

## Открыть

- `index.html` — полная демонстрация: все глифы, реальные контексты Aura, размеры 16/20/24/32,
  подача «глиф / плашка», тёмный и светлый фон.
- `inspect.html` — технический лист: каждый глиф в 64 px и мелкие размеры рядом.
- `?only=window|panels|volume|engines|providers|glyphs|compare|rules` — оставить один блок (удобно для скриншотов).
- `?theme=light` — сразу светлый вариант.

## Что внутри

65 канонических глифов и 79 алиасов поверхностей (`nav-*`, `tray-*`, `section-*`, `engine-*`,
`model-*`, `provider-*`, `filter-*`, `action-*`, `sound-*`).

Контракт:

| Параметр | Значение |
|---|---|
| viewBox | `0 0 24 24` |
| Ключевые линии | 18 × 18, поля 3 px |
| Штрих | 2 px, `round` caps / joins |
| Цвет | `currentColor` для всех UI-иконок; оригинальные цвета — только у знаков облачных провайдеров |
| Заливки | точки, треугольник Play, шкала моделей, фирменные знаки |

## Решения

- **Строго монохромно — кроме знаков провайдеров.** У набора нет API для цвета.
  Оранжевый назначает контейнер (активный пункт, статус), а не сам SVG. Исключение —
  Gemini, Groq, OpenAI и Hugging Face в селекте провайдеров: они используют
  оригинальные цвета из приложенных SVG.
- **Навигация:** «Основные» — сетка 2 × 2, а не шестерёнка. Шестерёнка на 18 px
  превращается в шум; сетка читается силуэтом.
- **Документ** — лист с залитым уголком: аккуратный сгиб без тройного стыка линий.
- **Игровой режим** — контурный вариант референса: корпус контроллера, крупная крестовина
  и две кнопки разного размера. Не пустой силуэт.
- **Производительность** — оставили иконку, которая уже интегрирована в приложение
  (круговая шкала с стрелкой), а не нашу прежнюю полукруглую.
- **«Голосовые команды»** — речевая плашка с тремя точками. Шеврон `>_` внутри
  плашки отвергнут на ревью: на 17 px он слипается с контуром и читается как терминал.
- **«Движок редактирования»** — карандаш с одной линией обоймы у ластика, без
  внутренней черты. Из трёх показанных вариантов выбран он; слайдеры и палочка
  со искрой отклонены.
- **Движки:** облачный режим — серверная стойка, локальный — ноутбук, CPU — чип
  с кристаллом, CUDA **и Parakeet** — официальный знак NVIDIA, Whisper — официальный
  знак OpenAI. Логотипы вписаны в 24-сетку как заливка — это осознанные исключения
  из контурного стиля.
- **Провайдеры:** Gemini, Groq, OpenAI и Hugging Face — официальные знаки в
  оригинальных цветах. Это единственное цветовое исключение в наборе.
  У Gemini сохранён оригинальный артворк: маска звезды и размытые цветные пятна
  (`feGaussianBlur`), поэтому знак переливается, а не заливается одним градиентом.
  OpenAI по бренду белый (`#FFFFFF`), а не `currentColor`: в списке он не сереет
  и не становится оранжевым при наведении.
- **Модели:** семейство `bars-1…bars-5` — это шкала размера/качества, а не отдельные
  бренды. Turbo и Qwen вынесены в bolt / hexagon.
- **Громкость:** четыре состояния `volume-0…volume-3` (выкл / тихо / средне / громко)
  с crossfade в демо. В приложении иконка будет меняться по порогам слайдера.
- **Parakeet** — знак NVIDIA, **Whisper** — знак OpenAI. **Zen** — чайная чашка,
  **Sci-Fi** — голова робота.
- **Ключ** — горизонтальный, с круглым кольцом и двумя зубцами. **Sparkles** — две
  четырёхлучевые звезды, без палочки и точки.
- **Звезда GitHub** в приложении остаётся жёлтой — это существующее исключение, не часть
  набора.
- **Заголовки карточек** получают иконку 18 px слева от названия (карта в
  `src/icon-system-integration.js`, `CARD_TITLES`). Утилитарные глифы переиспользуются:
  `globe` у обоих языковых разделов, `clock` у истории и таймера оверлея.
- **Языки остаются текстом.** В списках «Язык интерфейса», «Язык распознавания» и
  «Язык перевода» строка языка показывает двухбуквенный код (`RU`, `EN`, `DE`…), как в
  трее. Исключения — служебные строки: `auto` получает `globe`, `layout` — `keyboard`.

## Следующий шаг

После утверждения: заменить inline-SVG в `src/index.html`, `src/tray-menu.html` и
динамические строки в `src/main.js` на вызовы `AuraIcons.svg()`, сохранив текущие размеры
и точки монтирования. Алиасы уже названы по поверхностям, чтобы миграция была механической.

Бриф для независимой версии набора (для сравнения) — `docs/design/ICON_SYSTEM_BRIEF.md`.

## Интеграция в приложение

Набор уже подключён к рабочему UI (2026-11-07):

- `src/icon-system.js` — копия этого реестра; загружается классическим скриптом.
- `src/icon-system-api.js` — ES-модульный фасад (`getIcon`, `getBrandIcon`, `iconBody`, `hydrateIcons`).
- `src/icon-system-integration.js` — заменяет статические inline-SVG в окне настроек и трее
  на глифы набора, сохраняя классы и размеры из текущего CSS.
- `src/index.html` и `src/tray-menu.html` — `<script src="icon-system.js">` перед модулем.
- `src/main.js` и `src/tray-menu.js` — переведены с `src/icons.js` на новый фасад;
  динамические кнопки, тосты, копирование и статусы используют `getIcon()`.
- Провайдеры, движки и звуковые темы в кастомных селектах получают иконки через
  существующий `getSelectOptionIconKey()`; языки остаются текстом (код в трее).
- Старый `src/icons.js` не удалён и не используется приложением; он остаётся только
  для исторического каталога.
