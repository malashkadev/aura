# E2E-чеклист Aura 1.2.0 (пост-аудиторский ручной прогон)

- **Сборка:** тег `v1.2.0` (коммит — `git rev-parse v1.2.0`), dev-режим (`npx tauri dev`) или свежая локальная сборка
- **Цель:** подтвердить рисковые сценарии, не покрываемые статическими гейтами
- **Формат:** проходить по порядку, отмечать `[x]`; при падении фиксировать шаг, ожидание/факт, скриншот

---

## 1. Онбординг-тур (5 шагов, Docked Footer)

Сброс: DevTools → `localStorage.removeItem("aura_onboarding_completed")` → перезапуск.

- [ ] Тур запускается автоматически; ровно 5 шагов: «Способы распознавания» (`#card-engine`) → «Язык и словарь» (**вкладка «Текст»**, `#card-language`) → «Умная вставка» → «Хоткеи и оверлей» (`#card-hotkey`) → «История» (`.card-history`)
- [ ] Вырез подсвечивает правильную карточку на каждом шаге (нет пустого выреза); карточка центрируется
- [ ] Подвал тура не перекрывает подсвеченную карточку (`.tour-active-padding` работает при скролле)
- [ ] «Назад» / «Далее» / «Пропуск» / «Начать работу» работают; после завершения тур не повторяется

## 2. Гейминг-режим при активной записи (CONC-01)

- [ ] Начать диктовку → во время записи включить игровой режим (трей)
- [ ] Запись немедленно отменяется, оверлей скрывается, микрофон освобождается, зависаний нет
- [ ] После выключения режима диктовка снова работает (хуки поднялись, «Already recording» не залипает)

## 3. Длинная облачная диктовка (FAULT-03: 45 c → 600 c)

- [ ] Облачный движок → диктовать непрерывно 2–5 минут
- [ ] Финализация завершается успешно, текст вставлен полностью (обрыва на ~45-й секунде нет)

## 4. Fallback облако → локальный

- [ ] Невалидный ключ API (или сеть отключена) → диктовка → появляется уведомление «Cloud unavailable — used local model instead», текст вставлен локальной моделью

## 5. Мультиязычные тосты (DE / FR / PT)

- [ ] Сменить язык UI на `de`: «Скопировать отчёт диагностики» → тост success-стиля; сохранение настроек → success
- [ ] Повторить для `fr` и `pt` (регекс `kopiert` / `copié` / `sucesso`)
- [ ] Провокация ошибки (неверный ключ) → error-тост, не success

## 6. Защита от двойного старта записи (CONC-03b)

- [ ] Дважды быстро нажать хоткей старта → вторая попытка отбивается, активная сессия одна, аудиоустройство не дублируется
- [ ] Stop после этого работает штатно, можно начать новую запись

## 7. Стоп во время старта устройства (WASAPI warmup, CONC-03a)

- [ ] Нажать стоп/отмену сразу после старта (первые секунды инициализации) → UI не виснет, состояние консистентно, повторный старт ок

## 8. Выход из приложения (About → Выход)

- [ ] «О программе» → «Выход» → приложение завершается: окно закрыто, трей исчез
- [ ] В диспетчере задач не осталось процессов whisper/parakeet серверов
- [ ] Повторный запуск приложения проходит штатно

## 9. Офлайн-типографика (Onest)

- [ ] Отключить интернет → запуск UI → шрифт Onest применяется (DevTools → Network: нет запросов к Google Fonts)

## 10. Команды редактирования (2-командный фокус)

- [ ] Выделить текст → «исправь ошибки» → замена in-place с исправленной грамматикой
- [ ] Выделить текст → «переведи на английский» → перевод in-place
- [ ] «сократи текст» (и подобные) → НЕ команда: вставляется как обычная диктовка без задержек
- [ ] Инлайн-гайд «Голосовые команды» показывает ровно 2 команды; чипы совпадают с реальными фразами; проверить на 2–3 языках UI

## 11. Гард буфера обмена (FAULT-04) — опционально

- [ ] Занять буфер обмена сторонней утилитой (или заблокировать) → вставка Ctrl+V не выполняется, старое содержимое буфера НЕ попадает в документ; видна ошибка

## 12. Минор: копирование из истории

- [ ] Кнопка копирования записи истории → визуальное состояние «copied» (галочка) и возврат через 1.5 c; контент в буфере корректен

## 13. Маркер позиции курсора (`|`)

- [ ] Автозамена `С уважением, |` → продиктовать триггер → курсор стоит в заданной позиции (после запятой), а не в конце вставленного текста
- [ ] Шаблон с двумя `|` → курсор ставится по первому, второй остаётся литералом
- [ ] Проверить live-диктовку, повторную обработку из истории и потоковый режим (Parakeet)

## 14. Блокировка/разблокировка Windows (WTS)

- [ ] Начать запись → Win+L → разблокировать → отпустить хоткей: запись завершается один раз, хоткей не «залипает»
- [ ] После разблокировки новая сессия стартует с первого нажатия, без двойного старта

## 15. Автоповтор хоткея

- [ ] Удерживать хоткей старта/стопа 3–5 с → сессия не начинает и не завершает запись повторно
- [ ] Проверить в toggle- и hold-режимах

## 16. Тур: альтернативная карточка (Parakeet/облако)

- [ ] Переключиться на Parakeet или облачный движок → сбросить онбординг → шаг 2 подсвечивает карточку автозамены (`#card-replacements`)
- [ ] Текст шага 2 в этом режиме рассказывает про автозамену; вырез не уходит в угол и не остаётся пустым

## 17. Индикатор движка и запуск после установки

- [ ] После готовности движка чип статуса не показывает «запуск…» (нет фантомного таймера)
- [ ] Установить свежую сборку → «Запустить Aura» → приложение стартует без прав администратора
- [ ] Повторить установку поверх (upgrade) → запуск после установки работает; при желании проверить silent `/S /R`

## 18. Переключение раскладки на хоткее (Caramba Switcher)

Требует живой проверки: юнит-тест не строит реальный `KBDLLHOOKSTRUCT`.
Unicode-инъекция приходит в хук как `vkCode = VK_PACKET (0xE7)`, символ — в `scanCode`.

- [ ] Запущена Caramba Switcher (и/или PowerToys Keyboard Manager) → нажать и отпустить хоткей `Alt+V` → в поле не появляются `v`/`м`
- [ ] Обычный ручной набор `v` и `м` сразу после сессии проходит без подавления
- [ ] `Ctrl+V` (реальная вставка) не подавляется
- [ ] В логе появляется один WARN `Suppressed injected target-key ...` на сессию

## 19. Нативный бэкап и восстановление настроек

- [ ] Вкладка «О программе» → «Экспортировать» → открывается нативный системный диалог Windows «Сохранить как» с предложенным именем `aura-settings.json`.
- [ ] Отмена диалога → файл не создаётся, тост об успешном сохранении НЕ появляется.
- [ ] Выбор пути и сохранение → файл записывается строго по выбранному пути, появляется success-тост «Файл настроек сохранён».
- [ ] Проверить содержимое файла: это валидный JSON, ключи `api_key_*` отсутствуют.
- [ ] Попытка импортировать файл > 2 МБ или невалидный JSON → отклоняется с сообщением об ошибке.
- [ ] «Импортировать» валидный бэкап → появляется модальное окно подтверждения с оранжевой кнопкой «Подтвердить». Нажатие «Подтвердить» применяет настройки.

## 20. Карточка первого запуска (Base-модель)

- [ ] Удалить скачанные модели (или чистая установка) → вкладка «Основные»: сверху отображается компактная карточка с рекомендацией скачать Base-модель (~145 МБ).
- [ ] Карточка выполнена в стандартном стиле `.card` без кричащей оранжевой рамки; кнопки «Скачать Base» и «Проверить микрофон» выровнены по высоте (36px).
- [ ] Клик «Скачать Base» → стартует скачивание с индикацией прогресса. После завершения скачивания карточка первого запуска исчезает.
