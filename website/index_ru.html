Как это устроено

Принцип работы

Голосовой ввод встроен прямо в систему: без лишних окон, буфера обмена и переключения контекста.

Глобальный хоткей

Нажмите Alt + V в любом окне. Aura слушает речь в фоне, не перехватывая системный фокус.

Локальная обработка

Модели Whisper и Parakeet обрабатывают аудио прямо на вашем ПК — на процессоре или видеокарте.

Печать под курсор

Текст с расставленной пунктуацией и заглавными буквами сразу появляется там, где стоит курсор.

Преимущества архитектуры

Создано для максимальной производительности, приватности данных и мгновенной работы.

Локальная обработка и приватность

При выборе локальных моделей аудио не покидает ваш ПК. Никаких внешних серверов, скрытого логирования и телеметрии.

100% Офлайн Без отправки в сеть
0% Телеметрии Шифрование DPAPI

AURA

v1.0.10

Быстрый инструмент голосового ввода для Windows с поддержкой локальных нейросетей (Whisper, NVIDIA Parakeet) и передовых облачных моделей (Gemini, OpenAI, Groq).

Диагностика

Сохранять точный текст распознанной речи в диагностические логи. По умолчанию выключено для приватности.

Поддерживаемые движки

Гибкая архитектура позволяет использовать как мощные локальные нейросети, так и облачные API.

Режим работы Офлайн (CPU / CUDA)

Модель загружается в память и работает без задержек сети.

Поддерживаемые модели Base → Large v3 Turbo

От быстрой модели Base для любых ПК до сверхточной Large v3 Turbo.

Языки 99+ Языков

Автоматическая расстановка пунктуации и заглавных букв.

Архитектура NVIDIA Parakeet

Модель 0.6B оптимизирована для видеокарт NVIDIA.

Скорость В реальном времени

Мгновенный потоковый отклик без ощутимого ожидания.

Установка CUDA 1 Клик

Компоненты ускорения загружаются прямо из настроек программы.

Провайдеры Gemini, Groq, OpenAI

Поддержка любых OpenAI-совместимых эндпоинтов.

Для любых ПК Слабые ПК и ноутбуки

Печатайте голосом даже на легких ноутбуках без дискретной графики.

Безопасность Шифрование DPAPI

API-ключи шифруются локально средствами Windows.
